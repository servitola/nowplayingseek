# Compatibility

[← README](../README.md)

nowplayingseek stands on a private macOS door ([why](how-it-works.md#why-it-is-a-script)), so every
macOS build is a question of its own. This page is regenerated by a watcher that reads each new
build's binary diff in [blacktop/ipsw-diffs](https://github.com/blacktop/ipsw-diffs) and checks whether the
Now Playing gate moved. Only a build marked *tested* was actually run.

- **tested** — `make test-live` passed on this build.
- **expected** — not run here; the Now Playing gate in `mediaremoted` did not change on the way from a tested build.
- **at-risk** — the Now Playing gate in `mediaremoted` changed; expect it to break until tested.
- **broken** — tested and does not work.
- **untested** — not run here, and no unbroken chain of diffs leads to it from a tested build.
